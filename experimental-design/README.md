# Experimental Design

This directory contains examiner-facing material for the experimental design used in the submitted dissertation.

The main component is stimulus selection: the process used to choose four songs and five mixes per song for the final 5-mix listening study. The live interface remains in `study-interface/frontend-5mix/`; this directory explains and supports how its final stimuli were selected.

## Contents

- `stimulus-selection/` - final stimulus-selection documentation, config, source code, compact source evidence, and final-selection evidence.

The authoritative final audio files used by participants remain in `study-interface/frontend-5mix/assets/audio/study-stimuli/main-study/`.
