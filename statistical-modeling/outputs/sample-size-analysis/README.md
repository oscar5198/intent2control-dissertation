# Sample-Size Design Evidence

This compact folder supports Appendix C of the submitted dissertation.

The original development archive contained many intermediate simulation files.
Only the final evidence needed to verify the reported appendix statement is
retained here:

- `sample_size_summary.csv`: compact scenario-by-sample-size summary for the
  executed shortened-chain simulation fits.
- `sample_size_analysis_manifest.json`: provenance, design configuration,
  executed-fit counts, N=50 recommendation, and confirmation-fit details.

The retained evidence documents the design-stage analysis only. It was used as
recruitment guidance and is not a substitute for the final N=33 empirical model
outputs in `../stimulus-model/`, `../feature-model/`, and
`../final-model-summaries/`.
