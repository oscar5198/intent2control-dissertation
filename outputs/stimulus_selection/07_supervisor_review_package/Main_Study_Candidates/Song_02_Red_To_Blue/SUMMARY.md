# Song 02: Red To Blue

## Mix Pool

`Mix_Pool/` contains the complete candidate set considered during triplet selection for this song: 10 WAV files.

Use this folder only if you want to audition alternatives beyond the recommended Similar and Wide triplets.

## Recommended Triplets

- Similar Ratings triplet: McG-B; McG-G; McG-F.
- Wide Ratings triplet: McG-C; McG-H; McG-pro1.
- Primary recommendation: Wide Ratings, because it provides stronger acoustic/rating contrast for the main study candidate set.

## Selection Notes

The selected triplets were derived from the acoustic candidate pool, Brecht's historical preference ratings, and alignment verification outputs. The Wide Ratings set prioritises contrast, while the Similar Ratings set remains available as the closer-rating alternative.

Alignment verification assets are included in `Alignment_Figures/`. The corresponding listening files are in `Audio/Similar Ratings/` and `Audio/Wide Ratings/`.
