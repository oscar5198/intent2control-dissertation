# Supervisor Review Package

## What is being reviewed

Six candidate mixes per song:

- 3 acoustically diverse mixes with relatively similar previous ratings;
- 3 acoustically diverse mixes spanning a wider previous-rating range.

## Recommended review order

1. Read `selection_summary.md`.
2. Listen to the three WAVs in each condition.
3. Use `RapidSwitch.wav` to check alignment.
4. Consult `alignment_verification_booklet.pdf`.
5. Complete `supervisor_review_form.csv`.

## What to assess

- technical acceptability;
- audible distinctness;
- alignment;
- unnatural stereo behaviour;
- suitability for Similar or Wide condition;
- need for replacement.

## Important methodological notes

- stereo imbalance is not part of acoustic diversity;
- it is QC-only;
- no final study files have been generated;
- filenames use original Mix Evaluation Dataset names;
- no A/B/C labels are assigned;
- review WAVs are not participant stimuli.
