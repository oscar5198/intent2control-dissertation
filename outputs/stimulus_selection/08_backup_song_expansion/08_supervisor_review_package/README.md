# Backup Supervisor Review Package

## What is being reviewed

Four additional songs are provided as backup supervisor-review candidates. Each song has a Similar Ratings triplet and a Wide Ratings triplet, selected using the revised acoustic-first methodology.

## Recommended Review Order

1. Read `backup_song_selection_report.md` and `selection_summary.md`.
2. Listen to the three `_28sec.wav` files in each condition.
3. Use `RapidSwitch.wav` to check perceptual alignment.
4. Consult `alignment_verification_booklet.pdf`.
5. Complete `supervisor_review_form.csv`.

## Notes

- Stereo imbalance is QC-only and is not part of acoustic diversity.
- Prior no-context ratings stratify already acoustically diverse mixes; they are not ground-truth quality.
- No final study files or frontend files were generated.
- Review WAVs use original Mix Evaluation Dataset names and no A/B/C labels.
