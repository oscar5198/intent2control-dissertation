How the study works

  1. Read the scenario

    Imagine yourself in the situation described.

  2. Listen to the three versions

    Click or tap a marker to play that version. You may replay the versions and compare them in any order.

  3. Rate each version

    Drag the Version A, Version B, and Version C markers on the shared 0-100 preference scale to show how much you would prefer to listen to each version in that situation.

  4. Briefly explain your ratings

    Write a short comment explaining why you gave each rating.

Additional information

  • You may listen to the versions in any order.
  • You may replay the versions as many times as you wish.
  • The preference scale uses Bad, Poor, Fair, Good, and Excellent anchors, while still allowing any value from 0 to 100.
  • You can continue only after completing all required ratings and comments.
