# Participant Materials

Approved Participant Information Sheet and consent files belong in this directory.

These approved documents are the authoritative source for participant-facing wording. Any participant-facing interface text must be checked against them before implementation and again before study freeze.

Store unsigned versions only. Files containing signatures, internal ethics correspondence, or unnecessary personal data must not be committed.

Word originals may be accompanied by carefully checked Markdown transcriptions. Transcriptions must be verified against the approved documents before they are treated as implementation references.

Changes to approved wording must not be made silently. Any change to approved participant-facing wording must follow the required ethics and QMUL approval process.

Expected materials:

- Approved Participant Information Sheet Word original.
- Approved consent form Word original.
- Optional verified Participant Information Sheet Markdown transcription.
- Optional verified consent form Markdown transcription.

Do not add signed forms, drafts that are not approved, internal review correspondence, or files containing unnecessary personal data.
